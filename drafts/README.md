# drafts/

Output tray for the `seo-content-machine` workflow graph (`/seo-draft
<topic>`).

Every file here is a **draft, never a publication**. The graph writes
`<date>-<slug>.md` with the fact-checker's flagged claims listed at the top
and a `status: DRAFT — NOT PUBLISHED` banner in the front matter. No
automation in this repository pushes anything in this directory to the
website. The webmaster reviews a draft, resolves the flags, and publishes by
hand — or doesn't. Deleting a stale draft is always safe.
