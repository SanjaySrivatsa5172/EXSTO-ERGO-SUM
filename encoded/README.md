# `encoded/` — captures of external repositories

This directory holds plain-text/markdown **encodings of external GitHub
repositories** requested for reference. Each file is a structured, greppable
capture of an out-of-repo source at a point in time.

**This is not manuscript content.** Unlike `derived/*.txt` (plain-text mirrors of
this project's own PDF deliverables), files here describe *other* projects and
carry no bearing on the EXSTO ERGO SUM submission. Do not treat anything here as
a source of truth for the Charter, manuscript, or online resources.

Each file records its source URL, capture date, and method in its header.
